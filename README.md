# Personal Expense Tracker

A web-based expense tracking application built using Python, Flask, and PostgreSQL to help users record and manage their income and expenses.

## Features

- Track income and expenses.
- Store transaction records in a PostgreSQL database.
- View financial summaries, including income, expenses, and balance.
- Simple and user-friendly web interface.

## Tech Stack

- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Database Connectivity:** Psycopg
- **Frontend:** HTML, CSS, JavaScript

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Chanchal3007/Personal-Expense-Tracker-.git
cd Personal-Expense-Tracker-
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure PostgreSQL

Install PostgreSQL and create a database for the application. Configure your database connection using your local credentials. Do not publish passwords or other secrets in the repository.

### 5. Run the application

```bash
python app.py
```

Open the local address shown in your terminal in a web browser.
